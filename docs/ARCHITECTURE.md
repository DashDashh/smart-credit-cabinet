## Архитектура

Три сервиса:

```
┌─────────────┐     ┌─────────────┐     ┌─────────────────┐
│  Frontend   │────▶│   Backend   │────▶│ Decision Engine │
│  (React)    │◀────│  (Java)     │◀────│   (Python)      │
└─────────────┘     └─────────────┘     └─────────────────┘
                           │                      │
                           ▼                      ▼
                    ┌─────────────┐        ┌─────────────┐
                    │ PostgreSQL  │        │ model.pkl   │
                    └─────────────┘        └─────────────┘
```

| Сервис | Технологии | Назначение | Порт |
|---|---|---|---|
| **Frontend** | React + TypeScript | ЛК клиента и сотрудника банка | 3000 |
| **Backend** | Java / Spring Boot | Оркестратор: приём заявки, моки ФНС/БКИ, состояния | 8080 |
| **Decision Engine** | Python / FastAPI | Скоринг и принятие решения | 8000 |
| **PostgreSQL** | PostgreSQL 16 | Хранение заявок, истории статусов | 5432 |
